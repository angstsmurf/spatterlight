Del Test
Exercises ADRIFT del (delete last character).

Unflushed: the deleted character is still in the HTML walker buffer (works everywhere).
Flushed: the character was already committed past a tag boundary -- needs Gargoyle garglk_unput_string. CheapGlk, transcript, and Parchment leave it in place.

Commands: unflushed, flushed style, flushed br, help.

Delete Lab
A quiet room for testing del. Type help for commands.

> help
Commands: unflushed, flushed style, flushed br.

> unflushed
Unflushed: abc + del -- expect ab
Result: [abc]

> flushed style
Flushed style: a + bold x + del -- expect a on Gargoyle; ax on CheapGlk/transcript/Parchment
Result: [ax]

> flushed br
Flushed br: a + br + del -- expect a then blank line everywhere (Gargoyle cannot unput newlines; CheapGlk/transcript/Parchment have no unput)
Result: [a
]
