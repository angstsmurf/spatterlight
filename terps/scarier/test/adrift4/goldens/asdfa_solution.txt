# A.S.D.F.A. -- A Short Damn Fantasy Adventure (asdfa.taf), 3rd One-Hour Game
# Competition, 2003.  35 tasks, 8 rooms, four NPCs (Rancid, Otto, Toto, Chef).
#
# Seven tasks carry ACT type=4 v1=5 -- TASKs 2, 4, 7, 13, 15, 18 and 31 -- and
# nothing else scores, so the maximum is 35 and this route takes all seven
# ("Your score is 35 out of a maximum of 35.  (100%)").  Exactly one task ends
# the game: TASK 21 [s] at the Entrance while holding the deed (RESTR type=0
# v1=7 v2=1), ACT type=6 v1=0.
#
# The intro ends in "...press a key...<waitkey>" -- the only waitkey in the
# whole game (grep the decoded .taf and there is just the one).
# 2026-08-16: the row sets SCR_SKIP_WAITKEY=1, so the pauses are transparent.
# They never were answered by the blank lines here -- until the fix, the pause
# read did not honour the "#" comment convention and ate this header instead,
# which is why the blanks below reached the game as ordinary empty commands.
# They are turns the route was derived with, so they stay.
# FOOTGUN -- do not delete the two leading blanks as "filler": TASK 0 is [*] in
# room 0 [The Story So Far...] and its only action is to move you to room 1, so
# one of them is the throwaway command that buys the walk into the Entrance.
#
# FOOTGUN -- DO NOT EXAMINE THE SHELF.  The Pantry description all but begs
# you to ("a single shelf that is just crying out for someone to come along
# and examine it"), and TASK 5 [x shelf] answers "you find absolutely nothing"
# while quietly setting the flag that TASK 6 [sw failed] tests.  From then on
# leaving the Pantry runs TASK 6 instead of TASK 7, and TASK 7 is the only
# source of the sword.  Nothing ever clears the flag, TASK 7 is rep=0, and
# without the sword TASK 31 [sit *chair*] can never fire -- which means no
# TASK 11 [d], no cellar, no deed, and the game is silently unwinnable.
# TASKs 22/23 [*cheat*] are the author's own nod to this: the response
# depends on whether TASK 6 has already fired.
#
# The chain:
#   x cauldron     TASK 2 in the Kitchen, +5 -> the key (out of poor Barble).
#   open door      TASK 4, +5.  Pure gift: the pantry door is not actually
#                  locked (northeast works without it), and TASK 3 [n] -- the
#                  other user of that flag -- guards a direction the Kitchen
#                  does not even have.
#   sw             TASK 7 out of the Pantry, +5 -> the sword.  Same move as
#                  the plain southwest exit; the task is what arms you.
#   sit chair      TASK 31 in the Sitting Room, +5.  Needs the sword held, and
#                  it is what sends Toto down to the Cellar (ACT type=1) and
#                  sets the flag TASK 11 [d] tests at the Top Of Steps.
#   se then nw     TASK 8 leaving the Sitting Room puts Otto in it; TASK 9
#                  [nw] (RESTR type=2 on TASK 8) is the way back to him.  This
#                  route does the cellar trip in between, so the axe is in
#                  hand when Otto turns up.
#   kill toto      TASK 13 in the Cellar, +5 -> the axe, and Toto is removed.
#   give axe       TASK 15 to Otto, +5.  This is the switch on the coffin:
#                  TASKs 16/17/19 all carry RESTR type=2 v1=16 v2=1 (task 15
#                  NOT done) and are refusals; TASK 18 wants it done.
#   open coffin    TASK 18 back in the Cellar, +5 -> the deed.
#   s              TASK 21 at the Entrance, holding the deed.  You wake up,
#                  and Rancid pockets the bottle of Nightmare Inducer fluid.
