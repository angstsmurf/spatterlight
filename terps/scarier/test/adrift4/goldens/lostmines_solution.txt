# THE SPINE IS ONE CHAIN OF FAVOURS, and it is strictly ordered:
#   take ring (in the mine) -> give ring to bartender -> ask bartender about
#   boulder (he hands over a pencil) -> sign coupon -> give coupon to
#   bartender (he hands over a beer) -> give beer to gus -> blast the blockage.
# T34/T35/T39/T28 each carry the previous link as a restriction, so there is
# no way to shortcut it.
#
# TWO GATED EXITS:
#   EXIT room=0  IN -> 13 is T22, restricted on T21 `wear` (the hard hat),
#     so the hat has to come out of the closet at Home before the first trip
#     into the mine.  That forces the outward leg to reach the far end of the
#     map (Home is at the west edge, the mine at the east) and come back.
#   EXIT room=14 N -> 15 is gateTask=36 wantDone=1 -- `use cheese on rat`.
#     The cheese comes from the wooden box in the Cabin.
#   EXIT room=10 U -> 11 is gateTask=23 wantDone=0, i.e. the gambling room
#     closes for good once you swap the decks, and T23 teleports you back
#     down to the bar anyway.
#
# TWO CONTAINERS THAT MUST BE OPENED, NOT TAKEN.  `take box` on the roof gets
# "It's too heavy to lift, it'd be easier to just look in it here", and `take
# pillow` gets "You have no use for a lumpy pillow" -- in both cases the noun
# you actually want is inside, so it is `open box` / `take dynamite` and
# `open pillow` / `take cards`.
#
# THE DYNAMITE IS DECORATIVE.  T40's restrictions are only "matchbook held"
# and "T41 done" -- it never checks for the stick.  Taking it is what the
# fiction wants, not what the engine needs.
