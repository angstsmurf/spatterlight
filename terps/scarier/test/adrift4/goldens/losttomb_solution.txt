# 10+5+5+5+10+5+5+5+10+10+5+10+5+20+10+10+5+5+5+5+10+5+10 = 175, and the route
# below fires every one of them.  The `score` check on the second-to-last
# line reads 165/175; the winning `up` is T49's last +10.
#
# Six things cost a replay each and are the reason this script looks the way
# it does:
#
#  (1) THE DYNAMITE MUST GO IN THE HOLE BEFORE IT IS LIT.  T59 (light it while
#      holding it) starts EVENT 9, which fires T61 "BOOM! YOURE DEAD!" two
#      turns later.  T60 (+5) is the in-the-wall version.  The crack is also
#      hidden until `x walls` reveals it, and the object it becomes is called
#      "hole" -- `put dynamite in crack` is not understood.
#
#  (2) RUPERT KEEPS HIS OWN CLOCK.  EVENT 8 [TIFFIN TIME!] has a random start
#      of 50..80 turns; when it fires it sets VAR 0 [Rupert] to 0 for three
#      turns, and every "ask rupert to ..." task is gated on that variable.
#      A request swallowed by tiffin fails with a flavour message ("the lid is
#      too heavy for you"), not a refusal, so it reads like a wrong solution.
#      The second sarcophagus is therefore asked for TWICE below -- the first
#      ask lands mid-tiffin under this seed.
#
#  (3) THE WALL ROOM IS A TIMED TRAP AND THE SPEAR ONLY FITS LATE.  Rupert
#      trips the brick on the way back through, both doors shut and the walls
#      start closing (EVENT 2, one step every two turns: 12 -> 10 -> 8 -> 6
#      feet).  `jam spear in walls` answers "The walls are too far apart at the
#      moment to do that" until they reach 6 feet, which is turn 7 after the
#      hand-in-the-hole ask -- hence the nine `z`s.  Two more turns bend the
#      spear and open the north door enough to squeeze out.
#
#  (4) THE PILLAR SINK TAKES A TURN.  EVENT 6 [PILLAR CHECK] runs T30 at the
#      END of the turn the fourth statue is placed, so the ruby it reveals is
#      not there to take until the turn after -- the bare `z` before
#      `take ruby` is that turn.  Without it `take ruby` silently does nothing
#      and the mask can never be completed (T40 needs the ruby held), which
#      strands the run at 155/175 with no error message anywhere.
#
#  (5) NEVER CLIMB OUT OF THE WELL HOLDING THE MASK.  T33 is `ACT type=6
#      v1=1` -- a LOSING ending.  T34 is the near-miss ("the rope creaks, you
#      climb back down"), and the intended route is to send the mask up on its
#      own: mask into the rucksack, rucksack tied to the rope (T32 +10), then
#      ask Rupert to wind the handle (T36 +5).  He drops the rucksack back
#      down empty and leaves the mask waiting in the Well Room.
#
#  (6) THE MASK MUST BE WORN, NOT CARRIED, TO READ THE WALL.  T45/T46/T47 all
#      use restriction `type=0 v2=2` = "worn by the player" (screstrs.cpp
#      restr_object_in_place case 2), and T44 -- the plain "hundreds of lines
#      of red and blue" description -- is the v2=8 "NOT worn" counterpart.  So
#      `x wall` while merely holding the finished mask reads as a failure that
#      looks exactly like a right answer, and quietly costs 20 points.  The
#      author's own hint says so obliquely ("...maybe the wall will become
#      clear when looked at with the right attitude... ...or eyes...").
#
# The hint text above is not from a published walkthrough -- there is none.
# It comes out of `SCR_DUMP_TASKS=1`, which prints the file's per-task

# Veteran Knowledge.
#
# The file contains no <waitkey> tag (harness/waitkey_audit.py), so the row
# needs no SCR_SKIP_WAITKEY.
#
