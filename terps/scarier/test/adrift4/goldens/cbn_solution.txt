# Competition, 2003.  39 tasks, 12 rooms, one NPC (Rudolph the guard).
#
# Nine tasks carry ACT type=4 v1=5 -- TASKs 2, 4, 8, 13, 15, 16, 17, 18 and 19
# -- and nothing else scores, so the maximum is 45 and this route takes all
# nine.  Four tasks end the game (22-25, all ACT type=6 v1=0); which one fires
# is decided by two flags when you finally walk west out of the car park, and
# TASK 22 -- rules changed AND 101 Classics smashed -- is the one the game
# itself calls "the best possible ending in the game".
#
# Seven <waitkey>s: the intro's "...press a key...", and one in the MIDDLE of
# each `x desk` message in Chap's Office ("...finds...<waitkey> nothing!", then
# "Again you look and... <waitkey>this time you find a pen!").  The pen is what
# `change rules` needs -- without it you get "You've nothing to change them
# with!" and silently lose two of the nine awards.
# 2026-08-16: the row sets SCR_SKIP_WAITKEY=1, so the pauses are transparent.
# They never were answered by the blank lines here -- until the fix, the pause
# read did not honour the "#" comment convention and ate this header instead,
# which is why the blanks below reached the game as ordinary empty commands.
# They are turns the route was derived with, so they stay.

# turns, and one of them is the throwaway command that TASK 38 turns into the
# move from room 0 [The Story So Far...] into room 1; drop them and the game is
# unwinnable.  The two that DID feed the desk pauses are the ones that went out
# 2026-08-16.
#
# The chain:
#   open door        TASK 2 -- +5 for opening a door, and the joke is the point.
#   give cd rudolph  TASK 4 -- the CD is not an object (you are "carrying
#                    nothing"; TASK 1 [drop *cd*] is a refusal), yet giving it
#                    works and Rudolph explodes.  He otherwise blocks NE out of
#                    the corridor (TASK 6, RESTR type=3 v3=2 = NPC 0 present).
#   x desk x2        TASK 12 then TASK 13 -> the pen.
