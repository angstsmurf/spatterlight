# A Day at the Iachini House -- Michael Iachini, ADRIFT 4.00 (iachini.taf,
# 19,083 bytes, "Created using ADRIFT with Butcher Basic ALR", last updated
# August 2001).  27 rooms, 68 tasks, 5 events, 4 integer variables (coord,
# str, keynum, ph), no NPCs at all.  A chore game: the family is out, you have
# a handwritten to-do list, and the six items on it are the puzzle chain.
#
# WIN, 115 out of a maximum of 115 -- the declared maximum, and it is exactly
# reachable.  T30 `turn on * television *` in the front of the family room is
# `ACT type=6 v1=0`; the only losing move in the game is T13 `sit *stair*`
# before T9 has repaired it.
#
# The score arithmetic is worth stating, because the file adds up to more than
# it can pay out.  Twenty-one tasks carry an `ACT type=4` and they total 140,
# but 25 of those points are unreachable:
#
#   * T51/T52/T53 are all `take * shower *` and each awards 10.  Every one of
#     them consumes the fluffy bath towel (`ACT type=0 ... v2=0 v3=0` -- move
#     obj71 nowhere) and puts a *wet* towel on a bar in its place, and nothing
#     in the game dries or replaces it.  So exactly one shower is ever
#     possible: -20.  T30 names task51 specifically, so it has to be the
#     upstairs bathroom (room 16).  T53 is a second copy of T51 that also says
#     room 16 -- it hangs the wet towel on the *basement* bathroom's bar, so
#     the author plainly meant it for room 24 and mistyped the room.
#   * T45 (add a basic disc at pH 6, +5) is dead: -5.  See the hot tub below.
#
# 140 - 20 - 5 = 115, which is what the game reports as its maximum.  The
# author's own arithmetic already assumed one shower and one pH award.
#
# Provenance: no published walkthrough.  Derived from `SCR_DUMP_TASKS` plus
# play; the game's own two-level HINT system (`hints`, then a question per
# room) confirms every chain.  keynum = 80 and the hot tub's starting pH = 10
# under the harness seed; both are set by immediate events on turn 1, so they
# do not move when the route changes.
