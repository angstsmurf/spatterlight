# dungeon crawl. Clod is a janitor's apprentice at the College of Wizardry,
# sent into Zivulda's dungeon. This is a menu-driven demo, not a free-text
# parser: each screen shows a single highlighted option, cycled forward with
# `\` (or `'`), chosen with `1`; `2` opens/closes the inventory, where `1`
# uses or equips (and unequips) the highlighted item. The highlighted option
# is kept after a choice, and the inventory cursor always opens on SWORD.

# the stone slab gone: task 923 (#E2R4) -- emerald in the second socket, ruby
# in the fourth. The other three emerald/ruby layouts (tasks 917-922) kill.
# The twelve #score-- tasks (1223-1234) are all collected on this route.
# Deterministic: no RNG is consulted (same result under any seed).
