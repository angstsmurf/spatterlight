# The Quest -- an untitled-by-its-author ADRIFT 4 RPG (adult), 250 tasks / 59
# rooms.  The first line below is *not* a command: the game opens with a
# "Please enter your name:" prompt, and "Corin" is the answer.  There are no
# <waitkey> pauses anywhere in this game, so this file has no blank lines at
# all -- every non-comment line is a turn.
#
# NOSEX (the game's own switch, advertised in the disclaimer) is the first
# command.  It disables the sex scenes; the route below is the "Dark Gem"
# branch, which needs none of the adult sub-quests.
#
# The engine of the game is an experience-point economy.  Six skills are
# bought from trainers at fixed thresholds, and the only one that actually
# gates the ending is CLIMB 3 (1250 exp), because "climb rock" at the Cleft is
# the sole way up to the temple.  "turn greater ghoul" in the northern
# Mountain Pass is repeatable at +50 exp a go and is the farm -- hence the
# twenty-one identical lines below.
#
# Endgame ordering is strict and is *not* what the author's own walkthrough
# says.  "ask <ally> about demon" is gated on a variable that only SUGGEST
# sets, so the King has to be given his sacrifice *before* the allies can be
# recruited, not after.  The five "kill demon" scenes then have to run in the
# order Jedimah -> Merna -> dragon -> Caroline -> Gelry, each gated on the
# demon-health variable left by the previous one.
#
# See fantasyworld_walkthrough.md for the full map and task analysis.
