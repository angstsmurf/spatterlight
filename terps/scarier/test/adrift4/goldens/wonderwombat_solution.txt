# Four survival meters (bladder, hygiene, smoke craving, alcohol) each move by
# one every five turns.  Only two of them can kill you and both are ~500 turns

# the rubbish-truck trip zeroes hygiene outright (wear the gas mask), and the
# beer binge is the one place the meters are deliberately driven to an extreme.
#
# TURN PARITY IS LOAD-BEARING from "buy beer" onwards: the Fantasy Land trip is
# entered when alcohol reaches 100 and left when it decays back to 99, so
# inserting or deleting a single turn anywhere earlier in this file moves which
# "drink beer" tips you over and how long the hangover takes.  Re-derive both
# counts if you touch anything above.
