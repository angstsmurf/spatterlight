# ***  BEST POSSIBLE IS 145/155 -- THE LAST 10 POINTS ARE AN AUTHOR BUG  ***
# The nine treasures are scored by T101-T109, each `RESTR type=0` on its own
# object with `v2=0` ("in room") and `v3=36` (room 35, "Home Free!") -- except
# **T109, the bag of doubloons, which has `v3=0`**.  In `restr_object_in_place`
# (screstrs.cpp) the `var3 == 0` arm of case 0/6 does not test a room at all:
# it tests `position == OBJ_HIDDEN`.  The doubloons start hidden (OBJLOC
# obj=11 pos=-1) and T81 (the zombie shot) moves them **onto** the corpse
# (`ACT type=0 v1=14 v2=3 v3=1` = onto surface 0), so from the moment they
# become obtainable they are no longer hidden and T109 can never pass.
# Leaving them hidden -- i.e. never shooting the zombie -- does score the +10,
# but forfeits T81's +20, so that trade is 10 points worse.  145 is the
# ceiling, and this route reaches it.  Compare the +2 stranded behind an
# EndGame action in `threemonkeys_solution.txt`.
#
# THE SCORE TABLE.  Sixteen `ACT type=4` in the file, and that is all of it:
#   T21  give poisoned cheese to rats        room 13   +5
#   T27  throw molotov                       room 17   +5
#   T36  pour bleach on monster              (any)     +5
#   T40  blow whistle                        room 27   +5
#   T49  pour weedkiller on plant            room 11   +5
#   T54  pour holy water on skeleton         room 28  +20
#   T81  fire blunderbuss  (at the zombie)   (any)    +20
#   T101-T109  one treasure delivered to room 35     9 x +10
# 25 + 40 + 90 = 155; T109's +10 is unreachable, so 65 + 80 = 145.
#
# HOW THE ENDING FIRES.  T110 `* drive *` (room 29, the Driveway) does three
# things: moves the player to room 35, moves **all held objects** (`ACT type=0
# v1=0` = all held) to room 35, and moves the car there.  The treasures do NOT
# have to be put in the car -- carrying them is enough.  EVENTS 25-33 are
# `starter=3 startTask=111` (1-based -> T110) with `time1=time2=1`, so the
# nine scoring tasks run on the turn AFTER `drive`; EVENT 43 [Delay] runs T120
# `Finish` (the file's only `ACT type=6`, v1=0 = win) on that same turn.  So
# the route needs one real turn after `drive` -- here a `wait`.
# `score` and `i` are meta-commands and do NOT tick events, which is why the
# `score` two lines before the end still reads 65: the +80 has not happened
# yet and there is no turn left afterwards on which to print 145.
# WINTEXT is non-empty, so `Congratulations!` is suppressed and the
# transcript ends on the game's own text -- the harness marker.
#
# CAPACITY IS EXACTLY 10 OBJECTS.  The endgame inventory has to be the nine
# treasures plus the torch, so every tool is dropped the moment it is spent:
# hook (after `open hatch`), bible (after `bless water`), whistle (after the
# bats), holy water (after the skeleton), plunger (after the toilet), iron key
# and sledge hammer (in the Bathroom), and the blunderbuss the turn after it
# is fired.
#
# *** ORDER TRAP 1: THE GHOST ROBBERY, TURNS 5-8. ***
# T48 `GHOST MOVING STUFF` is `rep=0`, gated on `RESTR type=3 v1=6` (the ghost
# is in the player's room) and its action is `ACT type=0 v1=0 v2=1 v3=1` --
# move ALL HELD to a random room of group 1.  It fires exactly once, whenever
# you first share a room with the wandering ghost, and it scatters your entire
# inventory across the house.  This route walks straight to Hallway<4> (room
# 21) carrying **nothing**, meets the ghost there on turn 7, and picks the
# torch up off the floor afterwards.  Do this first or it will happen later,
# at the worst moment, with a full pack.
#
# *** ORDER TRAP 2: THE MOLOTOV HAS AN 8-TURN FUSE. ***
# `light molotov` (Kitchen, room 9 -- the hob) starts EVENT 1, which runs T26
# `KILLED BY MOLOTOV` (a death) if you are still holding it when it expires.
# The walk from the Kitchen to the Toy Room (9 -> 5 -> 4 -> 1 -> 15 -> 17) is
# five moves, so `throw molotov` on the sixth turn is the whole margin.  Light
# it only once the cloth-and-vodka cocktail is already made.
#
# *** ORDER TRAP 3: DO NOT WASTE THE LOADED BLUNDERBUSS. ***
# `* fire * blunderbuss *` matches seven tasks.  T81 is the one worth +20 and
# it is restricted on `RESTR type=3 v1=0 v2=0 v3=8` (the zombie present), but
# it does NOT out-rank the others by room:
#   T70 / T76  room 11 (Conservatory) -- NO NPC restriction at all, so firing
#              anywhere in the Conservatory silently burns the shot;
#   T77  room 13 while the rats live, T78  room 27 while the bats live --
#              both shadow T81, so kill those two first (this route does);
#   T74 / T79 / T80  need T85/T86 `hit door with hammer`, never done here.
# The zombie wanders a 48-step path.  This route meets it on the Landing
# (room 15) on the way down from the Bathroom; if your run diverges, fire
# wherever you next meet it -- anywhere except room 11.
#
# *** ORDER TRAP 4: THE CONSERVATORY REFUSES TO GIVE UP THE HAMMER. ***
# T35 blocks `take` in room 11 until T49 (`pour weedkiller on plant`) is done,
# and it costs health to try.  The weedkiller is in the Laboratory, which is
# behind the iron-locked Wine Cellar door, which is behind the rats.  So the
# cheese chain gates the hammer, which gates `break wall`, which gates the
# Hidden Room and its +20.
