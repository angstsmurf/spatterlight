# THE CLOCK. EVENT 0 ("Beast Kills Susie") is a silent, unconditional 17-turn
# timer running from turn 0; if it ever fires it costs -17 (an `ACT type=4
# v1=-17`) and permanently locks the BAD ending (T10's restriction requires

# shotgun chain and shoot the Beast in the Playroom, then drain its fang in

# cancels the 17-turn clock before it ever reads out. This route does it in
# well under 17 turns, so the -17 never applies and the full 102 is banked.
#

# the window and the Beast shots -- no second load is scripted or needed.
# The ornate key (a "Way") sits in the Secret Room from the start and must
# be carried before the final `east` into the void, or Uncle blocks you
# ("No! Do not depart into the void without a Way.").
