# Ticket to No Where (Richard Otter, InsideADRIFT Summer Comp 2004).  You have
# missed the train and have until 4.00pm to reach a meeting at Grantby; the
# game is a 6.5-game-hour clock that ticks one minute per turn, so the route is
# turn-sensitive from end to end.
# Route: the author's own transcript from the comp package
# (competition/wthroughs/ticketwalkthru.txt), replayed verbatim.  That file
# marks its commands with nothing at all -- no prompt, no prefix -- so the
# commands were recovered by heuristic and four had to be put back by hand:
# the stray "2." the author typed (and the "n" the transcript merged onto the
# same line), the over-long "say donningby bahnhof umsteigen grantby to young
# girl", and one empty line the author entered by accident.  All four cost a
# turn and the clock notices, so all four are kept.
# 110/110 -- a genuine full score, and the same total the author reports.
# Reaching it needs two engine fixes made while deriving this route, both
# verified live against run400.exe under Wine:
#   * "drop <thing> in <container>" is Adrift's put-in handler wearing another
#     verb.  Five bits of litter go in the rubbish bin this way and are worth
#     2 points each; before the fix the priority "drop %text%" pattern swallowed
#     the "in bin" tail and answered "Drop what?".
#   * "all" does not range over what the player already carries.  With the open
#     bag of shopping in hand, "get all" takes the pamphlet only; SCARE used to
#     empty the bag as well, which then made the banana skin too heavy to pick
#     up and cost the fifth litter point.
# Exactly one pause, the intro's "Press ENTER to continue" (measured with
# SCR_MARK_WAITKEY=1); the blank line further down is the author's stray empty
# command.
# 2026-08-16: the row sets SCR_SKIP_WAITKEY=1, so the pauses are transparent.
# They never were answered by the blank lines here -- until the fix, the pause
# read did not honour the "#" comment convention and ate this header instead,
# which is why the blanks below reached the game as ordinary empty commands.
# They are turns the route was derived with, so they stay.
