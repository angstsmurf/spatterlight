# The patched route (SCR_ASSUME_PATCHES=1).  Two field-level repairs in the
# built-in patch table make the endgame reachable: task 36 "rope cliff" stops
# being Repeatable so its identical ReverseCommand can untie the rope again
# (the airport's own exits are all gated on the rope NOT being tied), and
# Hamish -- "He needs to be killed" -- gets the KilledTask the author left at
# 0, pointing at task 43 ^^smugglerdiesevent^^, which is what opens the hair
# shop north of the bridge.
#
# The route also has to work within the author's economy, which is tight
# enough that the faithful walkthrough's Super Atomic Blaster is unaffordable:
# 100 to start plus the vault's 750 is all the money in the game, the tape
# player costs 500, and "buy hair" tests for 150 still in hand (it never
# deducts it), leaving 200 for weapons.  So this route buys the 100 Gun and
# two lots of 50 armour instead -- the first lot is swallowed by run390's
# "cap a raise at the attribute's max" rule, since the player's max defence
# starts at 0, so the second is what actually lifts defence to 1.
#
# Hamish has 50 stamina and 50 defence; giving the King the tapes drops his
# defence to 0, so the Gun's 13 takes four shots, and he strikes first every
# round for 10 - 1.  With 39 max stamina that is three shots per visit, hence
# the two detours to the kitchen: "take food" is Repeatable with no repeat
# text and the ants event that would have ended it affects no task, so the
# cupboard heals +5 a turn for the whole game.
#
# 95 is the ceiling, not 100: "buy hair" carries two +5 actions and ADRIFT
# scores a task once, so the second never lands, while MaxScore counts both.
