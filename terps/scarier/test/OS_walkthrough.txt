#   line 1  `Tester`  answers Task2's %popupinput["First Enter Your UserName"]%

# ENGINE NOTES.  This game drove three fixes, all suite-verified:
#   * SetVariable `FOR Loop = 1 TO 3 : SET Bjvalue[Loop] = ... : NEXT Loop` used
#     to be a silent no-op (split_assignment cut at the first `=`), so every
#     card dealt as "Zero of Spades".
#   * The card line mixes %cardPicture[RAND(1,4)]% INSIDE a `<#if(..)#>` with
#     %cardType[RAND(1,4)]% outside it.  The runner holds the whole aggregate
#     message to Display and draws in text order; we now defer such a `<#..#>`
#     body raw (tag \003) so its substitution draws at the flush, in position.
#   * A sentinel emitted inside a stripped tag (`<wait %Tpaus%>` wrapping
#     `<#rand(5, 9)#>`) has no text position; it now sorts at the previous
#     entry's position instead of last, keeping its draw in push order.
#
# DOCUMENTED DIVERGENCE (1 xoshiro hunk, budgeted): "AiMReele99 wins." where FD
# says "Tester wins!".  PlayerWin is a Specific override on Stand1's

# message at Display, AFTER those actions, so its %aiPoints% reads 0.  Scarier
# renders the static skeleton at emit time and defers only random-bearing
