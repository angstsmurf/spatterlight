# Son of Camelot (SoC_ifarchive.blorb) -- the IF Archive build, 5.000026 /
# 2012-12-06, two months later than SoC.blorb (5.000025 / 2012-10-01).

# Same FULL WINNING route as SonOfCamelot_walkthrough.txt (same good ending:
# Megan saved AND the gold found) with one authored change worked around:
#
#   * The secret passage behind the closet became a real door mechanic.  In
#     5.000025 `enter closet` alone dropped you in and `down` opened the back
#     wall; here the closet has to be OPENED to be entered ("You can't go inside
#     the wooden closet!") and then CLOSED from inside before the back wall
#     slides aside ("Thud!  Your face has a painfully encounter with the back
#     wall" otherwise).  So: `open closet` / `enter closet` / `close closet`.
#
#   * Those two extra commands are two extra turns, and Megan's guided tour is
#     a turn-counted patrol -- leaving them in desynchronises her by two rooms
#     and the endgame `tell megan about merlin` fails with "You can't see
#     Megan!".  Two of the eight `z` waits before the closet are therefore
#     dropped, keeping the total turn count identical.  The alarm has already
#     rung by the sixth `z`, so the custodians are still away.
#
#   * No Adventure-Upgrade prompt: this build IS 5.0.26, so the OR-after-AND
#     bracket correction is already baked in and the host is never asked.
#
# Diff vs SonOfCamelot_expected.txt is exactly those three spots and nothing
# else -- which is the point of pinning both builds.  See that file's header for
# the route itself and for the two engine fixes this game needed.
