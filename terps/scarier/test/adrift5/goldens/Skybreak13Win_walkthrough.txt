# Skybreak! 1.3 by Colton Douglas Olds (ADRIFT 5) -- FULL WINNING playthrough.
#
# This is the SkybreakWin route re-derived against the 1.3 blorb release
# (games/Skybreak_1.3.blorb), which the author rebuilt after the .taf that
# SkybreakWin pins.  Same Storyteller ending, same character (Vela, a Human
# Storyteller+Earthling), same win condition: bank 10 anecdotes, 10 tales of
# adventure and 10 horror stories, at which point task SorcererEn2 fires the
# "obtain enlightenment" prompt on the next free encounter slot and
# "1) Retire" is the EndGame Win.  See SkybreakWin_walkthrough.txt for the
# mechanics in full; only the deltas are documented here.
#
# TWO deltas from the parent route:
#
#  1. Character creation, command 9: the parent picks talent `16`, 1.3 needs
#     `19`.  The talent list grew, so every index after the insertion point
#     shifts; 19 is the same Skill Specialization pick.  Everything else in
#     the 379-command prefix replays unchanged and lands on the same cargo
#     (9 anecdotes / 9 tales / 6 horror stories at Baba Yaga's Hut).
#
#  2. The 106-command tail is new.  The parent's tail banks its last stories
#     in the Ghooric zone; on 1.3 those encounter rolls fall differently, so
#     the remaining 1/1/4 stories are gathered by touring systems instead.
#     Derived with a depth-3 greedy DFS over the menu options (seek13c.py,
#     kept out of tree, same disposable-auto-player pattern as seek2.py):
#     take the whole branch when a lookahead gains cargo, otherwise burn
#     actions in the current system until the game reports "the currents have
#     shifted" -- the ship refuses to launch before that, which is what stalls
#     a naive `c`/`l` spammer -- then charge (`c`) and launch (`l`).
#
# Ground truth vs FrankenDrift: see the MAP row (golden-backed).
