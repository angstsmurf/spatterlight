# The Drunken Harlot -- kkennon, 2012 AIF Mini-Comp
#
# Five rooms, 60 authored tasks, no events at all: the whole game is a state
# machine over eight numeric variables and five character properties.  There are
# seven endings; this route takes the one the author calls canon, "The Master".
#
# The machinery, read straight out of the model:
#
#   Property4 Guarded     -- WEAR NECKLACE while alone (Task19).  The necklace
#                            (Object10) is on the skeleton at the bottom of the
#                            well, and SEARCH SKELETON (Task16) additionally
#                            requires you to be holding the brass lantern.
#   Property5 Controlling -- DRINK POTION (Task20), which needs Cherise to be
#                            blindfolded at the time.  The potion (Object8) is
#                            sewn into her dress, and SEARCH DRESS (Task17) also
#                            requires her to be blindfolded.
#   Variable5 CheriseSex  -- one point each, once only, from Task8 (fuck pussy),
#                            Task53 (fuck ass) and Task56 (suck cock).  All
#                            three need the first kiss (Task41) behind you.
#
# SLEEP in the bedroom then picks one of four endings by restriction:
#
#   Task23 Dead End        Guarded, not Controlling        -> Lose
#   Task24 Lovers End      Enthralled + Controlling        -> Neutral
#   Task25 Enthralled End  Enthralled, neither other       -> Lose
#   Task26 Controlling End Guarded + Controlling           -> WIN
#
# all four also demanding Variable5 = 3, Cherise present, and Location5.
#
# The ordering is the puzzle.  The first kiss (Task41) fires two system tasks:
# Task42 enthralls you if you are NOT Guarded, and Task43 pulls Cherise's
# blindfold off if you ARE.  So the necklace has to be worn before the kiss, and
# because the kiss then un-blindfolds her, both blindfold-gated steps -- SEARCH
# DRESS and DRINK POTION -- have to be done before it too.  Get either order
# wrong and you are locked out of Task26 for the rest of the run.
#
# The lantern is the other trap.  It sits on the nightstand in the bedroom
# (Object6, Location5), so you cannot fetch it until you have BOUGHT a ROOM, and
# you cannot buy the room until you have searched the corpse for the purse and
# greeted Arysa.  Going down the well without it drops you in the dark, where
# Task12 -- commands n/s/e/w/.../down/in/out, but pointedly not "up" -- is the
# Zork ending.
#
# The courtship is a plain counter: Variable1 Cherise reaches 3 from BRAG TO
# CHERISE, BUY DRINK FOR CHERISE and COMPLIMENT CHERISE, one point apiece, each
# gated on its own task not already being complete.  The drink one also needs the
# bar tab open (Task10).  At 3, PROPOSITION CHERISE flips from Task29 (the polite
# brush-off, exercised below at Variable1 = 0) to Task33, which sends her up to
# the bedroom.
#
# Deliberately avoided: TALK TO CHERISE, TALK TO ARYSA and LISTEN are the only
# three commands in the game that draw on the RNG (%CheriseTalk[RAND(1,5)]% and
# friends), so leaving them out keeps both harness columns at zero.  BUY DRINK is
# safe up to five -- Variable2 Drunk = 6 is Task14, the Drunk ending -- and three
# of them is exactly what Task6, the Arysa proposition, wants.
