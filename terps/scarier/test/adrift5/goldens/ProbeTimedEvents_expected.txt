Timed Events Test
This game exercises FrankenDrift timed-event support.

Sit still at the prompt. Without typing, you should see each of these on its own line:
  ~1s  Immediate time event: tick 1.
  ~2s  Immediate time event: tick 2.
  ~3s  ExecuteTask ran TaskFromTimer.
       Delayed time event has started.
  ~4s  Immediate time event: ending.
  ~5s  Delayed time event is ending.

Then try:
  start timed   — queues a TimeBased event; beats ~2s and ~3s after the command
  start mist    — SetLook via TimeBased; type look while it runs (~5s)
  start seconds — TurnBased + Seconds sub-event (~2s later, no further command needed for that beat); then wait for the turns beat
  timed pause   — prints text, pauses 2s, more text, pauses 1.5s, then finishes
  south         — leave the lab; DisplayMessage sub-events are OnlyApplyAt the lab
