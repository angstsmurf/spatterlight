# The Saga of Percy the Viking (Percy.taf) -- 2nd One-Hour Game Competition,
# 2003.  50 tasks, 2 rooms ([Mead Hall] and [End]), one NPC (Throgbert).
#
# Not a parser game at all: a five-stage choose-a-number CYOA driven entirely
# by variables.  There is no scoring system (no ACT type=4) and no EndGame
# action anywhere (no ACT type=6) -- the eight "- final ..." tasks 40-47 just
# teleport you to room 1 [End] after printing one of eight ranks, and the
# session then sits there until you quit.  This route takes the best rank that
# the arithmetic actually allows: "You're a prince among vikings!"
#
# Turn 1-2: Throgbert has to walk in before anything parses.  EVENT 0 puts him
# in the hall at the end of turn 2 if you simply wait -- typing at him earlier
# only earns "no idea how to do that", and the random unrecognised-command
# messages perturb the RNG stream enough to delay his entrance, so the two `z`s
# are load-bearing.  After that every stage's options print in the same turn
# you answer the previous one, so the five digits run back to back.
#
# Stage effects (ACT type=3; note the dump's RESTR variable index is the ACT
# index + 2, so ACT v1=0 is "men" = RESTR v1=2 and ACT v1=1 is "coins"):
#   1 Erinbor         TASK 2  -5 men, +20 coins   (2/3/4: -1/+10, -10/+1, 0/0)
#   1 attack everyone TASK 10 -10 men, +30 coins  (2/3/4: -5/+15, 0/+10, 0/0)
#   2 let her pass    TASK 19 no change           (1 kidnap Yasmina: -5 men)
