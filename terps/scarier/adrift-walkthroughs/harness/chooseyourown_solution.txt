# Choose Your Own... -- David Whyld, ADRIFT 4 (Summer Comp 2004).
# A gamebook, not a parser game: one room, 449 tasks, and every "command" is
# the number of a menu option.  Page state lives in variables, so the whole
# game is a state machine -- see chooseyourown_walkthrough.md for the map.
# There is no EndGame action anywhere in the file; every branch funnels into
# TASK 38 '- end game', which prints "THE END" and then keeps prompting.  The
# win marker is therefore a line of the ending text.
# This route takes the "do nothing" ending: Carl Jacobson refuses von
# Lastmere, survives the psychic duel by standing still, and marries Sharon
# Elson.  It is the deepest of the endings -- it is the only one that reaches
# von Lastmere's quarters *and* leaves both of you alive.
# Two die-roll pages are crossed on the way ("Press either [1] or [2]" =
# rolled 1-3 or 4-6): page 2012 (the gift shop's back room, [2]) and the
# psychic duel (page 191, [2] = your own powers blunt the blast).  Both are
# ordinary menu picks here, so the run stays deterministic.
# Blank lines are <waitkey> pauses, not commands.  The first two are the
# title and instruction screens; the rest are the "...press a key..." breaks
# inside long passages, and the last two are the epilogue and "THE END".
