Full verified playthrough (exit 0, 404 turns).  The intro is skipped at the

needs re-deriving.

Worth knowing while reading the transcript:

  * The game block declares "verb <examine>" with no default script at all
    (decompiled line 78).  A verb declaration is matched ahead of every built-in --
    ExecCommand tries user commands, then ExecVerb, and only then its own
    "examine "/"x " handling (V4Game.Part2.cs:4205-4240) -- and ExecVerb falls
    through action, then property, then the (empty) default, so EXAMINE prints
    nothing whatever it is aimed at.  X still works, because the verb is named
    "examine" and nothing else.  The EXAMINE lines below are therefore no-ops kept
    for readability, and anything the route actually depends on is written LOOK AT.
    The combination lock in the Outer Sanctum is the one place it matters: its
    "look" script is what asks for the code and creates the exits north and south
    (decompiled line 3231), so the script says LOOK AT COMBINATION LOCK.
  * Several ask/get_string prompts consume the following line, which is why bare
    YES / yes / 1 answers appear between commands.
