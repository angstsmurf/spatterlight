Escape from this house (CJN, QDK Pro 3.53, Quest 3.5) - raw command script for geas_walkthrough_runner.
Game system: Quest 4.  Win marker: "You are free".

David Welbourn's Key & Compass page for this game is a MAP ONLY (no command list),
so this winning path was derived by reading the game source (escape.asl). 15 rooms,
fully deterministic (no timers/RNG). Puzzle chain:
  snowman (hat+scarf+carrot+coal) -> Colin + pipe; pipe->Old Man = toy car;
  empty wallet->Old Man = silver coin; soap in toilet moves Old Man, drugged
  coffee -> sleeping man -> secret paper; paper in bathroom mirror -> safe combo
  -> photographs; wine+photographs+onion -> the lady gives the house key; all five
  toys + basket -> Colin gives the gold key; umbrella->balloon, knife->rubber
  pieces, gold key+rubber+silver coin on the driveway control box -> gates open.

The game is ASL 350, so every noun below has to be an object's full name, alias
or alt name -- Quest only matches a word taken from the middle of a name for ASL
391 and up (Disambiguate, V4Game.cs:4762-4772; fixtures/abbrev.asl).  Three of
those names are longer than the prose above suggests: the bathroom's cupboard is
`define object <Bathroom Cabinet>` (escape.asl:709), the man is `<Old Man>`
(378), and the slot on the driveway box is `define object <coin slot>` with
`alias <Control box with Coin Slot>` (787-788).  That last alias is shared with
`<Earthed coin slot>` (802), the object that replaces it once the rubber pieces
are on -- only one of the pair is ever shown, so the same typed phrase reaches
whichever state the box is in, and the two `use` lines below read identically
while landing on different objects.
