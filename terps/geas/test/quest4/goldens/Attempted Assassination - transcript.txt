Welcome to Attempted Assassination
----------------------------------------------------------------------------
Welcome to my first attempt at a text-based adventure game. Before you begin to play this game, please make sure you read the entire text file named AA - Read Me. If you don't, this game could be a little more confusing than you might want it to be.

If at any time you feel that you are stuck and there is possibly no way out of your situation, don't worry, there is. At any time in the game you can type in help to go to the help room. Here, you can find what you need to do to finish the game completely. Only do this if you do not want to complete the game by yourself.

If you have any other questions or comments about this game, then you can contact me through e-mail at mslot722@yahoo.com.
