King's Quest V - text adventure (full playthrough) - raw command script for geas_walkthrough_runner.
Game system: Quest 4.  Win marker: "HAPPILY EVER AFTER".

Run with:  --tick --seed 1   (timers must tick; the maze monster and Mordack's
black cat are RNG, so the navigation/wait counts below are tuned to seed 1).

Notes:
 * the first "look" is eaten by the opening "press any key" (get_string) at start.
 * long runs of "look" are deliberate waits for turn-based timers (desert thirst is
   a counter, but the inn rat, desert bandit, mountain/ocean/castle creatures, and
   Mordack's appearance are all timers that advance one tick per turn).
 * every noun is an object's alias or one of its alt names, never the raw name of
   a `define object` that has an alias.  The game is ASL 350, so there is no
   partial matching to fall back on either -- Quest matches a word taken from the
   middle of a name only for ASL 391 and up (Disambiguate, V4Game.cs:4762-4772;
   fixtures/abbrev.asl).  Two lines look odd because of it: the lamp Graham gives
   the old witch is `define object <lamp>` with `alias <large lamp>`
   (KQ5_Full_final_1124.asl:3432-3433), so it has to be TAKE LARGE LAMP, and the
   coin in the same cave is `<gold coin>` with `alias <coin>` (3418-3419), so it
   has to be the shorter TAKE COIN.  Most of the game's scenery is generous with
   `alt` lists (the ape-like creature answers to six names), which is why the rest
   of the script reads naturally.
 * desert/dark-forest/inn "save?" prompts are answered 2 (No); the gypsy skip
   prompt is 1 (Yes); the inn door menu is 1 then 2; the battle picks 1/2/3/4
   (tiger/rabbit/weasel/rain) to counter Mordack's insect/dragon/cobra/fire.
